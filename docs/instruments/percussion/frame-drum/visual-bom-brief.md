# Visual BOM Brief

Create one visual row per major item:

| Item | Visual needed | Notes |
|---|---|---|
| Hoop stock | board/strip with grain arrow | show straight grain for bending |
| Drum head | rawhide or synthetic head | include trim allowance |
| Lacing/tuning hardware | cord, lace, or tuner set | depends on tradition |
| Bending form/template | disk or template drawing | shop-made |
| Finish | oil/wax/shellac bottle | keep off head contact surface |
| Beater/tipper blanks | dowels or turned sticks | optional companion deliverable |

Use owned photos once shop materials are selected. Until then, use simple
drawings or labeled placeholders instead of unlicensed supplier imagery.
