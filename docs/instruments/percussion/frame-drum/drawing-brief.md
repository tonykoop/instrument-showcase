# Drawing Brief

Required drawing set:

- Hoop plan view with outside diameter, inside diameter, head seat, and center.
- Hoop cross-section with depth, wall thickness, and bearing-edge radius.
- Stave segment layout showing miter angle and rough/final dimensions.
- Steam-bending form showing diameter, stop block, and clamp positions.
- Optional lacing/tuning layout for selected tradition.

Use clear datums:

- Datum A: drum center plane.
- Datum B: hoop front bearing edge.
- Datum C: scarf joint or stave seam reference.

Mark drawings as first-prototype estimates until a physical build validates
roundness, head fit, and tension response.
